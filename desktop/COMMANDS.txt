TETRA(1) — every app and the commands that control it

  tetra help [app]                      this manual, or one app's page
  tetra help --json                     every command as data
  tetra <app> <command> [--param value …] [--yes] [--json]
  tetra <app> <command> value value …   the parameters in order

  Tags: [read] reads, changes nothing · [external] reads text others wrote · [side] changes something · [asks] needs your yes (--yes)
  Types: time = YYYY-MM-DD or YYYY-MM-DDTHH:MM (local) or ms; strings = a,b,c or a JSON list; json = a JSON object or list.
  Tetra must be running; the command line talks to it over a socket only this user can open.

APP — Tetra itself: show a page, read this manual.
  tetra app open --page home|photos|collections|people|files|mail|calendar|notes|timer|pills|maps|contacts|phone|messages|data|assistant|notifications|sync|settings|commands   [side]
      Show a page of Tetra (and bring its window up).
      --page: The page.
  tetra app manual [--app string]   [read]
      This manual: every app, or one app's commands.
      --app (optional): One app.

CALENDAR — Calendars and their events (.System/Calendar). AI switch: calendar.
  tetra calendar calendars   [read]
      The calendars: id, name, colour.
  tetra calendar events --from time --to time   [read]
      Every event happening between two times (repeats unfolded).
      --from: From.
      --to: Until.
  tetra calendar save [--file string] --calendar string --event json   [side]
      Write an event: a new one (no file), or over an existing file.
      --file (optional): The event's file (rel) to write over; leave out for a new event.
      --calendar: The calendar's id.
      --event: The event: {title, place, notes, allDay, start: {date, time}, end: {date, time}, rrule, alarms}.
  tetra calendar save-day --file string --day time --event json   [side]
      Change one day of a repeating event.
      --file: The event's file.
      --day: That day's start.
      --event: The event: {title, place, notes, allDay, start: {date, time}, end: {date, time}, rrule, alarms}.
  tetra calendar skip-day --file string --day time   [side]
      Cancel one day of a repeating event.
      --file: The event's file.
      --day: That day's start.
  tetra calendar end-before --file string --day time   [side]
      End a repeat before a day ("this and following" deleted).
      --file: The event's file.
      --day: The first day it no longer happens.
  tetra calendar split --file string --day time --calendar string --event json   [side]
      Change a repeat from a day on ("this and following").
      --file: The event's file.
      --day: From this day.
      --calendar: The calendar's id.
      --event: The event: {title, place, notes, allDay, start: {date, time}, end: {date, time}, rrule, alarms}.
  tetra calendar move --file string --calendar string   [side]
      Move an event to another calendar.
      --file: The event's file.
      --calendar: The calendar's id.
  tetra calendar trash --file string   [asks]
      Move an event to the Trash.
      --file: The event's file.
  tetra calendar keep --file string   [asks]
      Keep this copy of a doubled event; the other copies go to the Trash.
      --file: The event's file.
  tetra calendar trashed   [read]
      The events in the Trash, newest first.
  tetra calendar restore --name string --calendar string   [side]
      Bring an event back from the Trash into a calendar.
      --name: Its name in the Trash.
      --calendar: The calendar's id.
  tetra calendar new-calendar --name string [--color string]   [side]
      Make a calendar.
      --name: Its name.
      --color (optional): A colour, #rrggbb.
  tetra calendar set-calendar --id string --name string [--color string]   [side]
      Rename or recolour a calendar.
      --id: The calendar's id.
      --name: Its name.
      --color (optional): A colour, #rrggbb.
  tetra calendar delete-calendar --id string   [asks]
      Move a whole calendar to the Trash.
      --id: The calendar's id.
  tetra calendar refresh   [side]
      Sync with the other devices now.
  tetra calendar import-pick   [side]
      Choose an .ics or .zip to import (a file dialog in Tetra); answers its calendars by index.
  tetra calendar import --choices json   [side]
      Import the picked calendars.
      --choices: [{index, into}]: each picked calendar and the calendar id it goes into.
  tetra calendar export [--id string]   [side]
      Save a calendar, or all, as .ics/.zip (Tetra asks where).
      --id (optional): The calendar's id; leave out for all.
  tetra calendar settings   [read]
      Reminders on this computer, and starting with the computer.
  tetra calendar set-reminders --on true|false   [side]
      Reminders on this computer on or off.
      --on: On.
  tetra calendar set-autostart --on true|false   [side]
      Start Tetra with the computer, on or off.
      --on: On.
